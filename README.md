# 🍔 Caiky Lanches - Hub Digital & BioSite NFC

Hub oficial e BioSite desenvolvido para as Plaquinhas Inteligentes NFC do **Caiky Lanches** (Lagomar - Macaé/RJ).

## 🚀 Recursos
- **Cardápio Digital / Delivery:** Integração com Anota Aí para pedidos instantâneos.
- **Atendimento WhatsApp:** Mensagem pré-formatada direta para pedidos e suporte.
- **Conexão Wi-Fi Inteligente:** Cópia de credenciais com 1 toque + Modal com QR Code nativo.
- **Avaliação Google:** Link direto de 5 estrelas para impulsionar o perfil no Google Meu Negócio.
- **Carrossel Gastronômico:** Vitrine interativa com fotos reais dos lanches, pizzas e açaís.
- **Temas Dinâmicos:** Alternância entre Modo Escuro (Obsidian) e Modo Claro (Gourmet) com transição suave.
- **Performance & CWV:** HTML5 Semântico, CSS3 Modular e Vanilla JS ultraleve com pontuação 95-100 no Google PageSpeed / Lighthouse.

## 📦 Deploy
Hospedado globalmente na rede de borda ultrarrápida do **Cloudflare Pages**.
